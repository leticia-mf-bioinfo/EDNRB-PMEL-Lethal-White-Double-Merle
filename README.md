# EDNRB-PMEL-Lethal-White-Double-Merle

Genes are biologically fundamental. However, there are variants that express harmful conditions, which may even be incompatible with life. Under the regulation of melanocyte inducing transcription factor (MITF), the premelanosome protein (PMEL) gene is related to white coat color and deafness in double merle dogs (*Canis lupus familiaris*), while endothelin receptor type B (EDNRB) does the same in frame overo horses (*Equus caballus*) and goes further: it causes death.

# Objective

- To compare the genomic sequences of PMEL and EDNRB;
- To analyze their interactions with MITF;
- To understand how different loci result in such similar phenotypes: white coat, deafness, and ocular alterations;
- To understand why lethality is restricted to the horse.

# Method

1. I downloaded the FASTA sequences of PMEL from the dog and EDNRB from the horse from the National Center for Biotechnology Information (NCBI) database
2. I aligned them in Clustal Omega to compare the DNA
3. I calculated the identity and the score in Visual Studio Code (VS Code), using Python and Biopython
4. I used the Search Tool for the Retrieval of Interacting Genes/Proteins (STRING) to observe the interaction of MITF with PMEL and EDNRB

**Software used:**

- NCBI
- Clustal Omega
- VS Code
- Python
- Biopython
- STRING
