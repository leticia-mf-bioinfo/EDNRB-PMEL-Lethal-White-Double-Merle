# EDNRB-PMEL-Lethal-White-Double-Merle

Genes are biologically fundamental. However, there are variants that express harmful conditions, which can even be incompatible with life. Under the regulation of melanocyte inducing transcription factor (MITF), the premelanosome protein (PMEL) gene is related to white color and deafness in double merle dogs (*Canis lupus familiaris*), while endothelin receptor type B (EDNRB) does the same in frame overo horses (*Equus caballus*) and goes further: it is lethal.

# Objectives

- Compare the protein sequences of PMEL and EDNRB;
- Analyze their interactions with MITF;
- Understand how different loci result in such similar phenotypes: white coat, deafness, and ocular alterations;
- Understand why lethality is restricted to the horse.

# Methods
1. Downloaded the FASTA sequences of PMEL from dog and EDNRB from horse from the National Center for Biotechnology Information (NCBI) database;
2. Aligned them in Clustal Omega to compare the DNA;
3. Calculated identity and similarity using Python and Biopython in Visual Studio Code (VS Code);
4. Used the Search Tool for the Retrieval of Interacting Genes/Proteins (STRING) to observe the interaction networks between MITF, PMEL, and EDNRB in both species.

**Software used:**
- NCBI
- Clustal Omega
- VS Code
- Python
- Biopython
- STRING
