# EDNRB-PMEL-Lethal-White-Double-Merle
Os genes são biologicamente fundamentais. No entanto, há variantes que expressam condições prejudiciais, podendo até ser incompatíveis com a vida. As sequências PMEL e MITF estão relacionadas à cor branca e à surdez em cães, enquanto EDNRB faz o mesmo em cavalos e vai além: causa a morte.
