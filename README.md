# EDNRB-PMEL-Lethal-White-Double-Merle
Os genes são biologicamente fundamentais. No entanto, há a ocorrência de genes que expressam condições prejudiciais, podendo até ser incompatíveis com a vida. As mutações em PMEL e MITF estão relacionadas à cor branca e à surdez em cães, enquanto EDNRB faz o mesmo e vai além: causa a morte, porém em cavalos.
