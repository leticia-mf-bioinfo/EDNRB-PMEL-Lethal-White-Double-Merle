# EDNRB-PMEL-Lethal-White-Double-Merle

Os genes são biologicamente fundamentais. No entanto, há variantes que expressam condições prejudiciais, podendo até ser incompatíveis com a vida. Com a regulação feita pelo melanocyte inducing transcription factor (MITF), o gene premelanosome protein (PMEL) está relacionado à cor branca e à surdez em cães (*Canis lupus familiaris*) duplo merle, enquanto endothelin receptor type B (EDNRB) faz o mesmo em cavalos (*Equus caballus*) frame overo e vai além: causa a morte.

# Objetivo

- Comparar as sequências genômicas de PMEL e EDNRB;
- Analisar suas interações com MITF;
- Compreender como loci diferentes resultam em fenótipos tão semelhantes: pelagem branca, surdez e alterações oculares;
- Entender por que a letalidade se restringe ao cavalo.

# Método
1. Baixei as sequências FASTA de PMEL do cão e EDNRB do cavalo pelo banco de dados National Center for Biotechnology Information (NCBI)
2. Alinhei no Clustal Omega para comparar o DNA
3. Calculei a identidade e o score pelo Visual Studio Code (VS Code), por meio de Python e Biopython
4. Utilizei o Search Tool for the Retrieval of Interacting Genes/Proteins (STRING) para observar a interação de MITF com PMEL e EDNRB
  
**Softwares utilizados:**
- NCBI
- Clustal Omega
- VS Code
- Python
- Biopython
- STRING
