# EDNRB-PMEL-Lethal-White-Double-Merle

Os genes são biologicamente fundamentais. No entanto, há variantes que expressam condições prejudiciais, podendo até ser incompatíveis com a vida. Com a regulação feita pelo melanocyte inducing transcription factor (MITF), o gene premelanosome protein (PMEL) está relacionado à cor branca e à surdez em cães (*Canis lupus familiaris*) duplo merle, enquanto endothelin receptor type B (EDNRB) faz o mesmo em cavalos (*Equus caballus*) frame overo e vai além: é letal.

# Objetivos

- Comparar as sequências proteicas de PMEL e EDNRB;
- Analisar suas interações com MITF;
- Compreender como loci diferentes resultam em fenótipos tão semelhantes: pelagem branca, surdez e alterações oculares;
- Entender por que a letalidade se restringe ao cavalo.

# Métodos
1. Baixei as sequências FASTA de PMEL do cão e EDNRB do cavalo pelo banco de dados National Center for Biotechnology Information (NCBI);
2. Alinhei no Clustal Omega para comparar o DNA;
3. Calculei a identidade e a similaridade, usando Python e Biopython pelo Visual Studio Code (VS Code);
4. Utilizei o Search Tool for the Retrieval of Interacting Genes/Proteins (STRING) para observar as redes de interação entre MITF, PMEL e EDNRB nas duas espécies.
  
**Softwares utilizados:**
- NCBI
- Clustal Omega
- VS Code
- Python
- Biopython
- STRING
